Problem Statement: AI-Powered Criminal Network Analysis System.
<br> 
Criminal investigation data is fragmented across FIRs, CDRs, financial records, surveillance, social media and case databases. Investigators often have to manually connect this information, making it difficult to identify hidden relationships, cross-case connections, suspicious locations and missing information.
<br>
CRIMEX addresses this by connecting fragmented data into a unified, visual investigation platform.
